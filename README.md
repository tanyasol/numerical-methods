## 1. `FFT.ipynb` — Анализ спектра механической системы

**Название проекта:** Анализ вынужденных колебаний системы из трёх масс с помощью дискретного преобразования Фурье (ДПФ).

**Краткое описание:**
Проект моделирует динамику системы из трёх связанных масс и пружин, описываемой системой дифференциальных уравнений второго порядка. Численное решение системы затем анализируется с помощью дискретного преобразования Фурье для нахождения собственных частот колебаний.

**Реализованные методы:**
*   **Численное интегрирование ОДУ:** Для решения системы дифференциальных уравнений движения используется метод `scipy.integrate.solve_ivp`.
*   **Дискретное преобразование Фурье (ДПФ):** Для перехода из временной области в частотную применяется `scipy.fft.fft`.
*   **Спектральный анализ:** Построение спектрограммы (зависимости амплитуды от угловой частоты) для идентификации резонансных частот системы.
*   **Аналитическая проверка:** Теоретически рассчитанные собственные частоты системы накладываются на спектрограмму для верификации результатов численного моделирования.

## 2. `interpolation.ipynb` — Библиотека интерполяции

**Название проекта:** Сравнительный анализ методов интерполяции: Лагранж, барицентрическая и сплайны.

**Краткое описание:**
Проект представляет собой набор реализаций различных методов интерполяции функций по заданному набору точек. Основное внимание уделяется сравнению точности и устойчивости полиномиальной интерполяции Лагранжа и её более стабильной барицентрической формы, а также построению кубических сплайнов.

**Реализованные методы:**
*   **Интерполяция полиномом Лагранжа:** Классическая реализация, вычисляющая значения полинома в заданных точках. Также реализована её первая и вторая производные.
*   **Барицентрическая интерполяция:** Более вычислительно устойчивый метод, сравнивается с полиномом Лагранжа (используется `scipy.interpolate.barycentric_interpolate`).
*   **Кубический сплайн:** Реализован метод построения кубического сплайна (C¹ и C²-гладкого), основанный на решении системы линейных уравнений для нахождения коэффициентов полиномов. Визуализируются сам сплайн, его первая и вторая производные.
*   **Параметрический сплайн:** Демонстрируется построение параметрической кривой с помощью кубических сплайнов.

## 3. `MNK.ipynb` — Метод наименьших квадратов (МНК)

**Название проекта:** Реализация метода наименьших квадратов для нелинейной регрессии.

**Краткое описание:**
Проект демонстрирует применение метода наименьших квадратов (МНК) для восстановления параметров нелинейной функции по зашумленным данным. Задача сводится к решению системы линейных уравнений с помощью QR-разложения.

**Реализованные методы:**
*   **Нелинейная регрессия:** Восстановление коэффициентов `A` и `B` для функции вида `y = x / (A + Bx)`.
*   **Линеаризация:** Исходная нелинейная модель преобразуется в линейную относительно новых параметров.
*   **QR-разложение:** Для решения переопределённой системы линейных уравнений, возникающей при применении МНК, используется `np.linalg.qr`.
*   **Визуализация:** Сравнение исходной (истинной) функции, зашумлённых данных и регрессионной модели, построенной с помощью МНК.

## 4. `ODE_Newton_method.ipynb` — Численное решение краевой задачи для ОДУ

**Название проекта:** Решение краевой задачи для нелинейного ОДУ методом конечных разностей и методом Ньютона.

**Краткое описание:**
Проект посвящён решению нелинейной краевой задачи для обыкновенного дифференциального уравнения. Задача дискретизируется с помощью метода конечных разностей, что приводит к системе нелинейных алгебраических уравнений, которая решается многомерным методом Ньютона.

**Реализованные методы:**
*   **Метод конечных разностей:** Аппроксимация дифференциального уравнения на равномерной сетке, преобразующая его в систему нелинейных алгебраических уравнений.
*   **Метод Ньютона:** Для решения полученной системы нелинейных уравнений реализован итерационный метод Ньютона. Он включает вычисление матрицы Якоби (функция `J`) и решение системы линейных уравнений на каждом шаге.
*   **Визуализация:** Построение численного решения и его сравнение с аналитическим решением для оценки точности.

## 5. `PDE_3.ipynb` — Численное решение уравнения в частных производных

**Название проекта:** Решение уравнения Пуассона в двумерной области методом Якоби.

**Краткое описание:**
Проект представляет собой реализацию численного решения двумерного уравнения Пуассона (или Лапласа с правой частью) в прямоугольной области с заданными граничными условиями. Для решения используется итерационный метод Якоби.

**Реализованные методы:**
*   **Метод конечных разностей (сеточный метод):** Исходное дифференциальное уравнение в частных производных аппроксимируется на двумерной сетке с помощью пятиточечного шаблона (крест).
*   **Метод Якоби:** Реализован итерационный метод для решения полученной системы линейных алгебраических уравнений. В коде используется сходимость по норме разности между итерациями.
*   **Обработка граничных условий:** Включена реализация граничных условий второго (Неймана, `du/dn = 0`) и первого (Дирихле, `u = 0`) рода.
*   **Визуализация:** Построение трёхмерной поверхности решения с помощью `matplotlib.plot_surface`.

## 6. `RK2_Euler_methods.ipynb` — Методы Эйлера и Рунге-Кутты 2-го порядка

**Название проекта:** Реализация и сравнение явного метода Эйлера и метода Рунге-Кутты 2-го порядка (RK2) для решения систем ОДУ.

**Краткое описание:**
Проект посвящён реализации двух классических одношаговых методов численного интегрирования ordinary differential equations (ОДУ): явного метода Эйлера и метода Рунге-Кутты 2-го порядка. Демонстрируется применение методов для решения системы линейных ОДУ, а также визуализация фазовых траекторий.

**Реализованные методы:**
*   **Явный метод Эйлера (Euler):** Простейший одношаговый метод первого порядка точности. Реализована функция `Euler`, вычисляющая решение системы ОДУ.
*   **Метод Рунге-Кутты 2-го порядка (RK2):** Более точный метод второго порядка, реализованный в функции `RK2`. Использует вычисление двух коэффициентов (`k1` и `k2`) на каждом шаге.
*   **Сравнение методов:** На графике решения системы ОДУ демонстрируется разница в точности между методом Эйлера и RK2 при одинаковом шаге интегрирования.
*   **Фазовый анализ:** Построение фазовых траекторий для системы ОДУ, описывающей затухающие колебания, с визуализацией особой точки (начала координат).
